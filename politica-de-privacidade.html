Política de Privacidade

Aplicativo: Shopee Ofertas Automáticas

Última atualização: 28 de setembro de 2026

1. Objetivo

Esta Política de Privacidade explica como o aplicativo Shopee Ofertas Automáticas trata informações utilizadas para executar sua automação de publicação de conteúdo.

2. Informações utilizadas

O aplicativo pode utilizar dados necessários para a publicação de conteúdo, como informações de produtos, imagens, títulos, preços, links de destino e identificadores técnicos das contas e serviços autorizados pelo responsável pela automação.

3. Pinterest

Quando o usuário autoriza a integração com o Pinterest, o aplicativo utiliza a API oficial do Pinterest somente para as funções autorizadas, incluindo a criação e publicação de Pins na conta autorizada. O aplicativo não solicita acesso a contas de outros usuários.

4. Compartilhamento

As informações utilizadas pelo aplicativo não são vendidas. O acesso a serviços de terceiros ocorre somente quando necessário para executar a automação autorizada pelo usuário.

5. Segurança

Credenciais, tokens de acesso e segredos de aplicativos devem ser armazenados de forma segura e não devem ser publicados em código-fonte público.

6. Retenção e exclusão

Os dados são mantidos somente pelo período necessário para executar a automação ou enquanto a autorização permanecer ativa. O usuário pode revogar a autorização de integrações de terceiros e solicitar a exclusão de dados relacionados à automação.

7. Alterações

Esta política poderá ser atualizada quando houver alterações relevantes no aplicativo ou em suas integrações.

8. Contato

Para dúvidas sobre esta política ou sobre o tratamento de dados, utilize o contato disponibilizado pelo responsável pelo aplicativo.
